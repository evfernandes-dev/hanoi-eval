# Composição abstrata de blocos

N discos de X para Y = (N-1 discos de X para Z) + (disco N de X para Y) + (N-1 discos de Z para Y).

No primeiro bloco, Z é a haste auxiliar. No terceiro bloco, X é a haste auxiliar. O disco N é o maior e se move uma única vez. Use os documentos dos sub-blocos; não é necessário resolver o problema inteiro de uma vez.
